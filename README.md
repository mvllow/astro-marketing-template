# Astro Marketing Template

An accessibile, performant starting point for your next content-focused site.

## Usage

```sh
pnpm create astro@latest --template mvllow/astro-marketing-template
```

## About

This template is built with [Astro] and enriched by [Tailwind CSS](https://tailwindcss.com/).

## Contributing

Clone this repo:

```sh
git clone git@github.com:mvllow/astro-marketing-template
cd astro-marketing-template
```

Install dependencies with [pnpm](https://pnpm.io):

```sh
pnpm install
```

Start the dev server:

```sh
pnpm run dev
```
